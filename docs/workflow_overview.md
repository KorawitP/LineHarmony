# โฟลการทำงาน LineHarmony - ภาพรวมแบบง่าย

## สรุประบบ
LineHarmony เป็นระบบจัดวางข้อความภาษาไทยสำหรับบอลลูนการ์ตูน โดยคำนึงถึงรูปทรงและความสมดุล

---

## ตัวอย่างการทำงาน 1 เคส

### Input
```
ข้อความ: "ต้องไปรับการรักษาในที่นี่ครับ"
รูปทรง: square_like (สี่เหลี่ยมจัตุรัส)
```

### ขั้นตอนการทำงาน

#### 1. โหลด Config และ Prototype
```json
{
  "shapes": {
    "prototypes": {
      "square_like": "ต้องไปรับการรักษาในที่"
    }
  }
}
```
- อ่านข้อความต้นแบบ (prototype) สำหรับรูปทรง `square_like`
- วัดความกว้างจริงด้วยฟอนต์ THSarabunNew.ttf
- ได้ความกว้างฐาน (base_width) เช่น 97 px

#### 2. ตัดคำด้วย PyThaiNLP
```
Input: "ต้องไปรับการรักษาในที่นี่ครับ"
↓
Tokens: ["ต้อง", "ไป", "รับ", "การรักษา", "ใน", "ที่นี่", "ครับ"]
```
- ใช้ PyThaiNLP engine "newmm" ตัดคำ
- ตรวจสอบคำห้ามแบ่ง (non_breaking_words.json)
- รวมคำที่ไม่ควรแบ่ง เช่น "การรักษา" ไม่แยกเป็น "การ" + "รักษา"

#### 3. คำนวณ Adaptive Width
```
ความกว้างข้อความทั้งหมด: 120 px
ความกว้าง prototype: 97 px
อัตราส่วน (ratio): 120 / 97 = 1.24 (124%)

เกณฑ์:
- < 100%: ข้อความสั้น
- 100-200%: ข้อความปกติ ← ตรงนี้
- 200-300%: ข้อความยาวปานกลาง
- > 300%: ข้อความยาวมาก

ขยายความกว้าง: 97 × 1.24 = 120 px
```

#### 4. Greedy Packing - ใส่คำลงบรรทัด
```
max_width = 120 px

บรรทัดที่ 1:
  + "ต้อง" (15 px) → รวม 15 px ✓
  + "ไป" (10 px) → รวม 25 px ✓
  + "รับ" (12 px) → รวม 37 px ✓
  + "การรักษา" (35 px) → รวม 72 px ✓
  + "ใน" (10 px) → รวม 82 px ✓
  + "ที่นี่" (30 px) → รวม 112 px ✓
  + "ครับ" (18 px) → รวม 130 px ✗ เกิน!

บรรทัดที่ 1: "ต้องไปรับการรักษาในที่นี่" (112 px)
บรรทัดที่ 2: "ครับ" (18 px)
```

#### 5. Balance Optimization - ปรับสมดุล
```
ก่อนปรับ:
  บรรทัด 1: 112 px (93%)
  บรรทัด 2: 18 px (15%)
  → ไม่สมดุล! (std_dev = 47)

ลองย้ายคำ:
  ย้าย "ที่นี่" จากบรรทัด 1 → บรรทัด 2

หลังปรับ:
  บรรทัด 1: "ต้องไปรับการรักษาใน" (82 px, 68%)
  บรรทัด 2: "ที่นี่ครับ" (48 px, 40%)
  → สมดุลขึ้น! (std_dev = 17)
```

#### 6. ตรวจสอบกฎปลายบรรทัด
```json
{
  "disallow_line_end": ["และ", "หรือ", "เพราะ", "ใน"],
  "polite_words": ["ครับ", "ค่ะ", "คะ"]
}
```

ตรวจสอบ:
- บรรทัด 1 จบด้วย "ใน" → อยู่ในรายการห้ามจบบรรทัด!
- ย้าย "ใน" ไปบรรทัด 2

```
บรรทัด 1: "ต้องไปรับการรักษา" (72 px)
บรรทัด 2: "ในที่นี่ครับ" (58 px)
```

#### 7. รวมคำสุภาพ (ถ้าเป็นไปได้)
```
บรรทัด 2 จบด้วย "ครับ" (คำสุภาพ)
→ ไม่ต้องย้าย เพราะอยู่บรรทัดเดียวกับคำอื่นแล้ว
```

### Output สุดท้าย
```
ต้องไปรับการรักษา
ในที่นี่ครับ

บรรทัด 1: 72 px (60%)
บรรทัด 2: 58 px (48%)
สมดุล: ✓ (std_dev = 7)
```

## สรุปขั้นตอนหลัก

```
Input Text
    ↓
[1] โหลด Config + Prototype
    ↓
[2] ตัดคำ (PyThaiNLP + Non-breaking words)
    ↓
[3] คำนวณ Adaptive Width
    ↓
[4] Greedy Packing (ใส่คำลงบรรทัด)
    ↓
[5] Balance Optimization (ปรับสมดุล)
    ↓
[6] ตรวจสอบกฎปลายบรรทัด
    ↓
[7] รวมคำสุภาพ
    ↓
Output Text (แบ่งบรรทัด)
```

## ไฟล์สำคัญ

| ไฟล์ | หน้าที่ |

## จุดเด่นของระบบ

1. **วัดความกว้างจริง** - ใช้ฟอนต์จริง ไม่ใช่นับตัวอักษร
2. **Adaptive Width** - ปรับความกว้างตามความยาวข้อความ
3. **Balance Optimization** - ปรับสมดุลความกว้างแต่ละบรรทัด
4. **กฎภาษาไทย** - ห้ามจบบรรทัดด้วยคำเชื่อม, รวมคำสุภาพ
5. **Cache** - เก็บความกว้างที่คำนวณแล้ว เพิ่มความเร็ว
